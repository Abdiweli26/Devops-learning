

# Regions

A geographical area, containing multiple availability zones, which consists of one or more data centre.


**How to choose a AWS region?**
- Compliance
- Proximity 
- Availability
- Pricing 

## Availability zones

An isolated location within an AWS  region containing one or more discrete availability centres. A region is usually made up of 3 or more availability centres with 6 being it's max.


### Point of presence  (PoP)

An AWS infrastructure positioned closer to users to deliver content with lower latency.

Example

Edge Location:  A type of PoP used by services such as CloudFront to provide content to users with lower latency.
