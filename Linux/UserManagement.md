# User Management  

  

## Current User  

  

```bash  

whoami  

```  

  

## Display User Information  

  

```bash  

id  

```  

  

## Display Groups  

  

```bash  

groups  

```  

  

## Switch User  

  

```bash  

su username  

```  

  

## Execute as Administrator  

  

```bash  

sudo command  

```


# Group Management

1- Creating a group
2- Adding user to a group 



```
sudo addgroup

sudo usermod -ag [Groupname] [Username]
```
