# User Management  

  

## Current User  

  

```bash  

whoami  

```  

  

## Display User Information  

  

```bash  

id  

```  

  

## Display Groups  

  

```bash  

groups  

```  

  

## Switch User  

  

```bash  

su username  

```  

  

## Execute as Administrator  

  

```bash  

sudo command  

```
