# File Management  

  

## touch  

  

Create a file.  

  

```bash  

touch notes.txt  

```  

  

## mkdir  

  

Create a directory.  

  

```bash  

mkdir projects  

```  

  

## cp  

  

Copy files and directories.  

  

```bash  

cp file.txt backup.txt  

cp -r folder backup  

```  

  

## mv  

  

Move or rename files.  

  

```bash  

mv file.txt newname.txt  

```  

  

## rm  

  

Delete files and directories.  

  

```bash  

rm file.txt  

rm -r folder  

```
