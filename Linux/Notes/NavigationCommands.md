# Navigation Commands  

  

## pwd  

  

Displays the current working directory.  

  

```bash  

pwd  

```  

  

## ls  

  

Lists files and directories.  

  

```bash  

ls  

```  

  

Common options:  

  

```bash  

ls -l  

ls -a  

ls -la  

```  

  

## cd  

  

Changes the current directory.  

  

```bash  

cd Documents  

cd ..  

cd ~  

cd /  

```  

  

## tree  

  

Displays the directory structure.  

  

```bash  

tree  

```
