# Environment Variables  

  

## View All Variables  

  

```bash  

env  

```  

  

## Display Variable  

  

```bash  

echo $HOME  

```  

  

## Create Variable  

  

```bash  

MY_NAME=Abdi  

```  

  

## Export Variable  

  

```bash  

export MY_NAME=Abdi  

```  

  

## Display PATH  

  

```bash  

echo $PATH  

```
